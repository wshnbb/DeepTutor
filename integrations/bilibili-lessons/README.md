# 按需找 B站课程

给现有 DeepTutor Windows 桌面版增加两个聊天工具：按要求找课并导入、读取已导入课程的字幕。

**只有用户明确要求找课时才搜索。** 普通知识问答不触发，扩展没有定时任务或后台推荐。

## 安装

先启动桌面版，并确认已有搜索服务可用。在此目录用 PowerShell 7 执行：

```powershell
./install.ps1 -DesktopInstall '<DeepTutor Desktop 安装目录>'
```

安装脚本从桌面状态目录读取当前数据 home 和实际服务端口，使用安装自带的 Python。扩展复制到数据 home 的 `integrations/bilibili-lessons`，新增同名 MCP 和技能；不覆盖已有同名资源。其他 MCP 连接、模型选择、供应商凭据和未应用的设置草稿不作修改。

默认直接调用该实例现有的搜索服务，沿用用户已选的搜索提供方，不附带任何模型或密钥配置。如已有另一个本机搜索适配器提供 `GET /search?q=...`、返回 `{"results":[{"title":"...","url":"...","content":"..."}]}`，可显式传入 `-SearchOrigin 'http://127.0.0.1:<端口>'`。该地址只写入本机扩展的进程环境。

使用自定义 `DEEPTUTOR_DESKTOP_STATE_DIR` 的桌面实例还应传 `-StateDirectory '<桌面状态目录>'`。仅支持现有本机单用户账户；开启多用户登录后扩展会停止，不绕过身份验证。

## 使用

在普通聊天中说：

> 帮我找一个讲转差率的 B站视频，并带我学。

工具搜索一次，保留最多三个真实 BV 视频链接，检查公开视频信息，优先选择有字幕的相关视频，自动导入一节到沉浸式阅读。重复的视频复用已有资料，并返回可打开的阅读链接。

只查候选，不导入：

> 帮我找几个讲转差率的 B站视频，只列链接，不要导入。

“解释一下转差率”不是找课请求。继续学习已导入的视频时，读取已有字幕，不重新搜索。

## 内容边界

字幕取得后，按小段字幕和时间戳讲解；没有字幕或只有章节标题时明确说明，不把搜索简介当成讲课正文。默认不下载视频、不登录 B站、不转写音频。搜索和聊天使用用户现有提供方额度。B站的字幕与嵌入播放受其平台限制，导入成功不代表视频一定能在嵌入播放器中播放。

内容工作区禁用 MCP/技能继承时，需要为该工作区分配新增资源。工具只在上下文明确给出 `dt_workspace` 时选择对应空间，不扩大原有权限。

## 验证与移除

```powershell
python integrations/bilibili-lessons/test_lessons.py -v
```

测试覆盖普通和否定请求不搜索、网址校验与去重、重复导入复用、无字幕不得报告为口述字幕。测试不需要账号或联网。

在 DeepTutor 的 MCP 管理和技能管理中分别移除 `bilibili-lessons` 即可停用。已导入资料会保留；扩展目录可在停用后手动移除。升级 DeepTutor 后若内部 API 有变化，需重新验证。
